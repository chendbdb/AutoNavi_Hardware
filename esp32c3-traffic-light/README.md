# ESP32-C3 三色信号灯固件

这是一个 BLE 外设，设备名为 `AMAP-TRAFFIC-LIGHT`。收到 Android 桥接 App 的
`TL1,<序号>,<颜色>,<倒计时>` 指令后控制红、黄、绿之一。

## 灯光规则

- 红灯：倒计时大于等于 3 秒时常亮；小于 3 秒时按 0.2 秒周期快速闪烁。
- 绿灯：倒计时大于等于 3 秒时常亮；最后 3 秒按 0.5 秒周期闪烁。
- 黄灯：按 1 秒周期慢速闪烁。
- 主绿灯状态：GPIO3 的红色 LED（LED3）常亮，表示对向红灯。
- 主红灯状态：GPIO4 的绿色 LED（LED4）常亮，表示对向绿灯。
- 主灯闪烁期间，对应的对向灯保持常亮；黄灯或全灭时两只对向灯熄灭。
- 按住 GPIO21 按钮：暂停应用 BLE 灯态，主红黄绿熄灭，LED3 与 LED4 同时常亮。
- 松开 GPIO21 按钮：立即恢复按下前的灯态，并继续处理 BLE 指令。
- 按住期间收到的 BLE 指令会被安静忽略，不输出指令错误日志。

详细接线请查看 [`WIRING.md`](WIRING.md)。

## Arduino IDE 部署

1. Arduino IDE 的“开发板管理器”安装 `esp32 by Espressif Systems`。
2. 打开 `esp32c3-traffic-light.ino`。
3. 选择你的具体 ESP32-C3 开发板，例如 `ESP32C3 Dev Module`。
4. 修改文件顶部的 GPIO 和 `ACTIVE_HIGH`。
5. 上传后打开 115200 波特率串口监视器。

固件只使用 ESP32 Arduino Core 自带的 BLE 库，不需要另装第三方库。

## 接线

默认配置：

```text
GPIO0  ── 220Ω ──|>|── GND   红
GPIO1  ── 220Ω ──|>|── GND   绿
GPIO2  ── 220Ω ──|>|── GND   黄
GPIO3  ── 220Ω ──|>|── GND   LED3 红（主绿灯时亮）
GPIO4  ── 220Ω ──|>|── GND   LED4 绿（主红灯时亮）
GPIO21 ── 按钮 ───────── GND   按下启用 LED3+LED4 本地显示
```

不同 ESP32-C3 板卡的引脚引出并不完全相同；GPIO2
可能是启动绑带脚。若接上绿灯后无法正常下载或启动，请在复位/上电期间断开
GPIO2 灯线，或改用适合你板卡的普通输出脚并同步修改代码。

## 安全行为

- 蓝牙未连接：红、黄、绿按每盏 0.5 秒循环点亮，表示设备正在等待连接。
- 蓝牙连接成功：立即结束循环并全部熄灭，等待第一条灯态指令。
- BLE 断开：先全灭，然后从红灯开始恢复待机循环。
- 连续 8 秒未收到指令：立即全灭。
- 序号倒退或重复：忽略，防止旧包覆盖新状态。
- 切换颜色时先全灭，再点亮目标灯。

如果驱动的是 12V 信号灯、灯带或大功率 LED，不能直接接 GPIO；需使用
MOSFET/三极管驱动和独立电源，并共地。
